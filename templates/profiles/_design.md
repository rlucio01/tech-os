# _design.md — Padrões Visuais do Projeto

> Arquivo opcional para projetos com Frontend/UI. Lido pela skill `tos-design`.

## Stack de UI
- **Framework / Styling:** _(ex: React + Tailwind CSS + shadcn/ui)_
- **Ícones:** _(ex: Lucide)_

## Identidade Visual
- **Tema:** _(ex: Dark / Light / Sistema)_
- **Cor Primária:** _(ex: #38bdf8)_
- **Tipografia:** _(ex: Inter / JetBrains Mono)_

## Regras de UX
- Toda tela assíncrona deve tratar: `loading`, `empty`, `error` e `success`.
- Reutilizar componentes existentes antes de criar novos.
